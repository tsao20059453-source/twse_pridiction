# 固定股票池與基準指令

| 檔案 | 來源 | 用途 |
|---|---|---|
| `pool_top30_20260921.csv` | 2026-09-21 11:10 抓的成交金額前 30 名 | 重現論文最終版 |
| `pool_top30_20261025.csv` | 2026-10-25 23:17 抓的成交金額前 30 名（10/23 收盤資料） | **改動比較的固定基準** |

## 參數

- `--pool-csv`：固定股票池，不再抓執行當天的排行。
- `--as-of`：把這天視為「今天」，只用到這天為止的本地快取，不上網、不寫回快取；近 3 年區間也以這天往回算。
- `--purge-days`：walk-forward 清洗期（交易日）。**預設 10**（2026-10-26 起，修正訓練／測試標籤重疊）；設 `0` 為論文版的舊做法。
- 價格還原：**預設開啟**（2026-10-26 起）。先用 `data/chip/dividends.csv`（FinMind 除權息參考價）還原現金股利與配股，
  剩下單日仍超過 ±10.5% 的視為面額變更／減資，以開盤價推估；`--no-price-adjust` 關閉（重現舊結果）。
- `--chip-features`：模型加入三大法人、融資融券、月營收特徵（資料在 `data/chip/`，以 `tools/fetch_chip_data.py` 取得）。預設關閉。
- `--include-otc`：股票池納入上櫃股票（上市＋上櫃依當日成交金額取前 N 檔）。個股分析輸入上櫃代號會自動判別，不需此參數。
- `--score-profile`：最終決策分數權重。`low_model_weight_v1`＝論文版（0.30 安全＋0.20 報酬＋0.25 規則＋0.25 風險報酬）；`rule_rr_v2`＝規則與風險報酬各 0.5。

## 基準一覽（固定基準股票池，`--as-of 2026-10-25`）

| 版本 | 指令差異 | 總報酬 | MDD | Sharpe |
|---|---|---|---|---|
| **誠實基準（目前預設；除權息＋面額變更還原）** | （不加參數） | 211.06% | −5.6% | 3.20 |
| 規則＋風險報酬 | `--score-profile rule_rr_v2` | 242.06% | −5.4% | 3.52 |
| 只做面額變更還原（10/26 下午的版本） | 需移除 `data/chip/dividends.csv` | 99.55% | −6.2% | 2.54 |
| 未還原價格 | `--no-price-adjust` | 109.30% | −5.57% | 2.65 |
| 舊做法（有洩漏、未還原） | `--purge-days 0 --no-price-adjust` | 73.13% | −5.60% | 2.17 |

注意：補上現金股利還原後（每次只差 1～4%），總報酬就從 99.55% 變成 211.06%；
代表單一回測的總報酬受路徑效應影響很大，**比較方案時請看多種設定（種子、股票池）的平均，不要只看單一數字**。

未還原價格時，2327 國巨 2025-08-25 一拆四（546 → 143）會被記成單日 −74%，持有的方案會出現一筆約 −72% 的假虧損；
各方案的比較因此失真，10/26 起一律以還原後的數字為準。

注意：清洗後報酬變高**不代表模型變強**。清洗後 return 模型的 OOS IC 由 0.020（t=1.92）降為 0.003（t=0.29），safety 模型 0.289 → 0.285；
報酬差異來自 return 分數排序改變、8 個持股名額換到不同股票（路徑差異）。改變隨機種子（42→7）只造成 73.13%→73.32%，故差異不是種子雜訊。

誠實基準指令：
```
python Pipeline_clean.py --mode backtest --symbol ALL --top-n 30 --no-investor-mode --pool-csv pools/pool_top30_20261025.csv --as-of 2026-10-25
```

## 論文版（總報酬 120.62%）

必須加 `--purge-days 0 --no-price-adjust`，並改用 `data\raw_snapshot_20260921`（論文版執行時資料只到 9/18；目前 data\raw 已含 9/21 收盤，直接跑會得到 121.00%）：

```
Rename-Item data\raw raw_current
Copy-Item -Recurse data\raw_snapshot_20260921 data\raw
python Pipeline_clean.py --mode backtest --symbol ALL --top-n 30 --no-investor-mode --pool-csv pools/pool_top30_20260921.csv --as-of 2026-09-21 --purge-days 0 --no-price-adjust
Remove-Item -Recurse data\raw
Rename-Item data\raw_current raw
```
同窗口加清洗期、未還原：總報酬 123.41%、CAGR 60.64%、MDD −8.57%、Sharpe 2.46、Calmar 7.07。
